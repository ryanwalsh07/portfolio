IMAGES
======

Every image on the site has a built-in placeholder. To replace one, save your
image into THIS folder using the exact file name below. It appears automatically,
no code changes needed. If a file is missing, the placeholder shows instead.

Export from Figma: select the frame > Export (bottom right) > PNG at 2x.
Keep each file under about 1 MB (tinypng.com shrinks them for free).

TAPSOS (home page card and case study)
  tapsos/                  Screens and icons from the approved TapSOS 2.0
                           Portfolio Pack. Only add files from that pack.
                           No MyJourney / NightCommute images on this site.
  tapsos/card/             Smaller JPEG copies of tapsos/screens (480px wide)
                           for the home page card's tilted wall. If a screen
                           changes, re-export its copy here too.

NightCommute has been retired: its case study and images are gone for good.

SHARING PREVIEW (the card shown when your link is pasted into LinkedIn, Slack etc.)
  share-card.png           1200 x 630.

Tip: names are case sensitive. "Share-Card.PNG" will not work; "share-card.png" will.
